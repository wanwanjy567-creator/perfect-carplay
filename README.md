# 完美 CarPlay（Perfect CarPlay）

**安卓车主完美使用 CarPlay 的终极硬件方案。**

## 为什么要做这个项目？

对于常用手机是安卓的车主来说，想在原车 CarPlay 车机上获得丝滑的导航和音乐体验，一直很折腾：
1. **第三方互联盒子体验差**：市面上各种 CarPlay 转安卓盒子，普遍存在卡顿、发热、断连或 UI 简陋的问题。
2. **放一台淘汰的 iPhone 在车里当专机，其实是最优解**：原汁原味的无线 CarPlay 体验，流畅稳定，且二手旧 iPhone 成本极低。
3. **但直接放手机进车里有两个致命痛点**：
   * **安全隐患**：夏天车内暴晒高温，手机锂电池极易鼓包甚至有起火风险，**必须拆掉电芯改直供电**。
   * **供电与开机难题**：拆掉电池只留保护板后，原车 USB 口供电能力不足，根本扛不住 iPhone 开机瞬间的峰值电流，会导致反复重启；且每次上车还得手动按开机键。

为了彻底解决以上问题，我设计了这块 **12V 转 5V / 4.2V 供电与开机触发底板**：直接取车内 12V ACC 电，**无电池安全隐患、扛得住开机峰值电流**，真正实现**上车通电自动开机秒连无线 CarPlay、熄火自动断电**的无感体验。

> **适用车型与车机：** 本板为通用 12V 车载供电方案，**不绑定单一车机型号**。大众 MQB（如帕萨特、迈腾）、奥迪、保时捷等任何**支持 CarPlay 且车内可取 12V ACC 电**的车型均可直接使用。

---

## 核心电路方案

* **主降压电路（12V → 5V）：** 采用 **TPS5450（5V / 5A 固定输出版）** 降压模块，尺寸 `40.64mm × 20.32mm`（标准 2.54mm 网格），提供充足电流余量。
* **自动开机触发（5V 路）：** 5V 直连卧式直插 `USB-A` 母座（D+ / D- 短接），通过短线接入 iPhone 11 尾插，实现上电自动触发开机。
* **假电池稳压供电（4.2V 路）：** 5V 经 `S5M / US5M` 硅二极管降压兼防倒灌，配合 `330Ω / 470Ω` 泄放电阻与 `4700uF / 10V` 低 ESR 电解电容吸收开机瞬时峰值电流，直接输出至电池保护板 `B+ / B-`。

## 关键元器件清单（BOM）

| 器件名称 | 规格 / 封装 | 作用说明 |
| :--- | :--- | :--- |
| **降压模块** | TPS5450（5V / 5A 固定版） | 主降压，12V 转 5V |
| **硅二极管** | S5M / US5M（SMC 封装，5A） | 降压至 ~4.2V 并防止电流倒灌 |
| **泄放电阻** | 330Ω 或 470Ω（0805 封装） | 稳定空载压降与断电泄放 |
| **滤波电容** | 4700uF / 10V（低 ESR 电解电容） | 稳压并扛住手机开机瞬时峰值电流 |
| **USB 接口** | 卧式直插 USB-A 母座 | 输出 5V 触发手机自动开机 |

## 嘉立创打板与上车前必测

1. **下载打板文件：** 直接下载本仓库根目录下的 [`my-cat_fabrication_files.zip`](./my-cat_fabrication_files.zip)。
2. **嘉立创下单：** 将下载的 `.zip` 压缩包直接上传至**嘉立创 PCB** 下单页，采用默认参数（板厚 `1.6mm`、铜厚 `1oz`）即可打板。

> **⚠️ 焊接与上车前必测（防烧机）：**
> 焊好降压模块、二极管、电阻、电容和 USB 母座后，**切勿直接接手机**！先通 `12V` 直流电进行空载测量：
> * `USB-A` 输出电压：约 **`5.0V`**
> * `B+ / B-` 输出电压：在 **`4.15V ~ 4.35V`** 之间
> 确认电压完全正常后，再焊接接入 iPhone 11 电池保护板。
